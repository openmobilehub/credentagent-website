CredentAgent

Privacy

What this website and its live demo collect, who receives it, and why. Last updated 2026-10-16.

The website

credentagent.ai is a static page with no analytics, no advertising and no cookies of its own. It is served by Vercel, which proxies pages hosted on GitHub Pages; both keep standard server logs (such as IP address, user agent and the page requested) under their own privacy policies. Your light/dark theme choice is saved only in your browser's localStorage under credentagent.theme.

The "In Claude / ChatGPT / Goose" tab embeds a YouTube video. It loads only when that tab is shown; your browser then fetches it from YouTube (Google), which handles that request under Google's privacy policy.

The live demo

The in-browser demo talks to a demo MCP store hosted by the project on Vercel. The store keeps your cart and order — the products, quantities, prices and order status — so the demo can work. If you complete a checkout with a wallet, the store receives what the wallet presents and records the result of the check on the order. All of this is demo data in a demo store: use only the test credentials the demo describes, never real payment details.

Ask AI

When you type a question into the demo's Ask box, it is sent with your recent questions and answers and your demo cart or order id to a function on credentagent.ai, which forwards it to an AI model provider — currently Nebius and Z.ai — to produce the answer. Requests are rate-limited by IP address. Don't type personal information into it. The AI can read the demo store and edit your demo cart; it can never check out, pay or touch a spending grant.

The library

The CredentAgent npm packages run on your own servers and send nothing to the project. What a deployment collects is up to the merchant running it.
